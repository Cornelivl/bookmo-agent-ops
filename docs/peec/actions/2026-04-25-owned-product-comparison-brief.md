## Selected task

Create a reviewable content strategy brief for Bookmo's first owned GEO page, starting with a primary page around artist booking software / booking agency software / full booking workflow.

This is the first task because Peec's strongest current signal is owned-page visibility: homepage, product pages, comparison pages, alternative pages, and listicle-style pages. The brief is a safe first artifact because it does not publish anything, send outreach, mutate Peec, deploy, or modify `booking-agent-crm`.

## Current recommendation

Start with a product/guide hybrid page, not a thin SEO landing page and not a listicle.

Recommended page:

- URL: `/artist-booking-software`
- SEO title: `Artist Booking Software for the Full Booking Workflow`
- H1: `Run the full artist booking workflow from one place`
- Core thesis: Bookmo gives booking agencies one central system for artists, buyers, venues, offers, contracts, advancing, schedules, and next actions — instead of another spreadsheet or disconnected tool.
- AI angle: Bookmo is moving toward making booking context accessible through an AI chat interface. Until the chat interface is live, phrase this as coming soon / directional, not as a current product promise.

## Why this direction changed

Founder review corrected the first draft:

- Do not frame the enemy as "another contact database." Better enemy: another Excel sheet, another disconnected tool, another place to check.
- Do not overuse "every show in motion" as the main headline. It is a positioning phrase, not a core GEO/search phrase, and can sound vague.
- Do not make the page mainly about CRM comparison. Bookmo is broader: a full booking workflow system where the tools and context teams need are easy to access, increasingly through AI chat.
- Keep and strengthen the section about what modern artist booking software should do.

## Copy iteration policy for SEO/GEO

It is safe, and usually good, to change the page copy after launch if changes improve clarity, accuracy, and topical authority.

Changing copy later does not inherently ruin SEO/GEO. Search and AI systems expect pages to be updated. The risk comes from making large, unfocused changes that alter the page's core intent, URL, entity associations, or claims without measurement.

Safe iteration rules:

- Keep the same URL if the page continues to target the same intent.
- Keep the core page intent stable: artist booking software / full booking workflow for booking agencies.
- Improve sections, examples, FAQ answers, internal links, schema, and product accuracy over time.
- Do not repeatedly rewrite the page into a different topic.
- Do not remove the main entity/category language that helps AI systems understand Bookmo.
- Keep redirects only if the URL must change.
- Log meaningful copy changes and measure Peec/SEO impact over 7/14/30 days.

Recommended approach:

- Ship a solid v1 once approved.
- Treat it as an authority asset that can be improved monthly.
- Make revisions based on Peec visibility, search impressions, AI retrieval, customer language, and product truth.
